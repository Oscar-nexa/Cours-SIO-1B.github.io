Retrouve et ajoute les cours de chaque matière.

Comment ajouter un cours ?

  1. Clique sur « Ajouter un cours » dans la matière concernée.
  2. Connecte-toi à GitHub, puis glisse ton fichier (PDF, Word, image…).
  3. Écris un petit message (ex : « Cours Maths – Probabilités »), puis clique sur Commit changes.
  4. Si tu n'as pas les droits d'écriture, GitHub te proposera de créer une Pull Request : valide-la, elle sera acceptée par l'administrateur.
  5. Attends 1 à 2 minutes : ton cours apparaît automatiquement ici.
